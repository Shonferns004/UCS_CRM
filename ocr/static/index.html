A scanner that stays here

    
Photos go to a local Python server, get read by Indra OCR, and come back as Markdown plus five fields. No cloud OCR, no account, nothing leaves this machine.


    
    
      
  • 
        
        
    Front, then backThe front carries the number, name and date of birth. The back carries the address and PIN code. Scan both and the details merge.
    
      
    • 
      
  • 
        
        
    Checksum checkedThe 12-digit number is validated with the Verhoeff checksum UIDAI uses, and flagged when it doesn’t add up.
    
      
    • 
      
  • 
        
        
    Raw output includedThe OCR tab shows the exact Markdown Indra produced, so you can verify a field against the source.

      Running the server
      
If the camera won’t open or this page says the server is offline, run python server.py inside the ocr folder and open http://localhost:8010. Camera access requires localhost or HTTPS.

    


    
Use only on documents you have permission to handle. The first run downloads the Indra OCR models (about 100 MB); after that, everything works offline.
