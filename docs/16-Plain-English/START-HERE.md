## 2. Very quickly, what is this system?

UCS CRM is a **company diary and office** for an NGO team. One website does these jobs:

| Plain job | What it really is |
| --- | --- |
| Keeping donor records | Who supports us, how much, when |
| Giving receipts | A proof of money received, like a shop receipt |
| Punching in and out | Who came to work, when, from where |
| Salary and loans | Who is paid what, and deductions for loans |
| Field officer follow-up | Calls/visits to donors, work hours, idle time |
| Beneficiary help | Food/kit distribution records to families |
| Events | Programs, activities, assets, volunteers |
| Communication | Chat, notices, help tickets, WhatsApp inbox |
| Reports & admin | Everything admins monitor every day |

## 3. The people in this system (roles)

| Role | Simple meaning |
| --- | --- |
| **Super Admin** | The overall boss — can see everything |
| **NGO Admin** | Runs daily operations of the NGO |
| **Accounts** | Money team — leads, donors, receipts, salary |
| **HR** | People team — attendance, leaves, letters, payroll |
| **FRO** | Field/telecall officer who talks to donors |
| **Recruiter** | Finds new staff (leads and candidates) |
| **Event Head / Manager** | Runs programs and events |
| **Developer / Social / Digital** | Technical and social-media team |
| **Worker** | Field worker; punches in/out for attendance |

## 4. How money flows (one short story)

A **FRO** calls a supporter → records the supporter as a **lead** → the **Accounts** team checks and verifies it → the supporter becomes a **donor** → when money arrives, Accounts **generates a receipt** → at the end of the month the money is matched with the **bank statement** and included in **reports**.
